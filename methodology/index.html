Methodology

From article discovery to evidence-grounded events

The news pipeline separates retrieval, food-specific relevance scoring, full Qwen triplet extraction, Mistral adjudication and Qwen event assembly. Each result remains traceable to its source article and evidence.

Public workflow

Seven stages in the news pipeline

The sequence below describes the implemented evidence flow from collection to the public repository.

01

Article collection

Candidate news records are discovered through approved search queries and source collections. Retrieval failures and duplicate text are audited instead of being interpreted as negative evidence.
02

Text preparation

Publisher boilerplate and malformed text are conservatively cleaned. Each retained article is split into bounded chunks while preserving the identifiers needed to trace every later claim.
03

Relevance classification

A food-specific classifier scores whether an article is likely to contain useful safety evidence. This is a retrieval aid, not the final event decision.
04

Full triplet extraction

Qwen extracts candidate triplets from every article chunk, then the complete set passes schema routing, semantic review, atomic correction and exact-evidence checks.
05

Mistral adjudication

Mistral reviews the completed Qwen triplet record and resolves which claims are supported, rejected, schema gaps or still unresolved before event extraction begins.
06

Qwen event assembly

Qwen combines the full article with the adjudicated triplets, assigns the article-level event label and builds grounded or ungrounded structured event objects.
07

Interactive repository

The website exposes source text, classifier metadata, model decisions, event fields, exact evidence and triplet audit trails so each record can be inspected.

Large-model event validation

Full Qwen triplet pipeline, then Mistral adjudication

Event validation begins with the complete triplet workflow. Mistral adjudicates that evidence only after all Qwen extraction, review and correction stages have finished.

A

Qwen candidate extraction

Every cleaned chunk is sent through the full FFLO-style extraction prompt. Each candidate includes a subject, predicate, object, entity types, confidence, evidence span and source identifiers.
B

Deterministic schema routing

Code checks entity types, predicates and permitted subject-object combinations. Candidates are routed as schema-valid, schema-invalid, schema-mismatch or zero-triplet chunks.
C

Qwen semantic review

A separate Qwen pass compares each candidate with its article excerpt and tests entailment, direction, relation choice, entity types and missed relations.
D

Atomic correction and recheck

Repairable claims are rewritten one at a time. A corrected triplet must pass the structure check, exact contiguous evidence checks and a second semantic review.
E

Mistral adjudication

After all Qwen triplet stages finish, Mistral adjudicates the accepted, corrected, schema-gap and unresolved candidates as one evidence record. Unsupported claims are rejected; uncertain claims remain explicitly unresolved.

Event assembly

How Qwen builds grounded and ungrounded events

Qwen performs event extraction only after Mistral adjudication. Event grounding records whether the structured fields can be traced through retained triplets to exact article evidence.

A

Lock the evidence inputs

Qwen receives the complete cleaned article together with the Mistral-adjudicated accepted, schema-gap and unresolved triplets. Article and triplet identifiers are preserved.
B

Assign the event decision

Qwen assigns relevant_event, irrelevant or unclear from the article and adjudicated evidence. Claim status is recorded separately, so an alleged or suspected event is not presented as confirmed.
C

Assemble the event object

For event-bearing articles, Qwen structures the food items, adulterants or issues, place, date, quantities, authorities, actions, laboratory context and exact evidence quotations reported by the source.
D

Separate grounded events

An event is grounded when its material fields are supported by the adjudicated triplets and traceable article evidence. Supporting triplet identifiers and quotations remain attached to the event.
E

Retain ungrounded events distinctly

If the article supports an event but one or more material fields cannot be linked to an adjudicated triplet, the event remains visibly ungrounded. It is not merged with grounded evidence or treated as independently verified fact.

Evaluation concepts

Precision, recall, soundness and completeness

Precision

Among articles predicted relevant, the proportion meeting the reference relevance criteria.

Recall

Among reference-relevant articles, the proportion recovered by the classifier.

Soundness

Whether a structured claim is supported by the article and the adjudicated evidence.

Completeness

Whether the pipeline retrieves and represents all in-scope evidence. Web discovery and model extraction cannot guarantee completeness.

Interpretation note

News reports are source claims, not independent laboratory verification. The event label records whether an in-scope event is present; claim status separately records whether the source describes it as suspected, alleged, pending, authority-reported or laboratory-confirmed. Ungrounded events remain distinct from grounded evidence.
